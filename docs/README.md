# Muninn documentation

Use these pages according to what you are trying to do:

| Goal | Page |
| --- | --- |
| Choose a cohort, focused view, or drill-down | [Analysis and reports](analysis.md) |
| Understand signal thresholds and intervention semantics | [Signal interpretation](signals.md) |
| Compare one day or one week of work with the preceding period | [Comparing periods](comparison.md) |
| Attribute locally controlled tools and suppress false positives | [Repository configuration](repository-configuration.md) |
| Measure whether an intervention helped | [Improvement workflow](improvement-workflow.md) |
| Understand what Muninn stores and omits | [Privacy and data model](privacy.md) |
| Add another coding-agent session format | [Session providers](session-providers.md) |

```bash
muninn --help
muninn analyze --help
muninn failures --help
```
